# Zombie animations

These are the animation names with a description listed in order

## Use

Idle ( standing in place looking around )
Walk1_InPlace ( Walking forward with arms down)
Walk_InPlace ( Walking forward with arms up )
Run_InPlace ( Running forward with arms up )
Attack ( Standing in place attacking by swinging arms forward )
Fallingback ( fall backward )
FallingForward ( fall forward)

## Dont use

Walk
Run
Walk1
